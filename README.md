# EB Meter Tracker Mobile V1

Mobile-first PWA prototype. It runs from a browser and stores meter readings in localStorage.

## Use on Android
- Open `index.html` from a hosted/static web location in Chrome.
- Add to Home screen.
- Set starting meter reading/date under Setup.
- Record/upload meter photos.
- Confirm the meter reading and save.
- View Home, Analytics, History.

## Important
This V1 is a prototype and does NOT contain the official Tamil Nadu tariff engine yet. It also requires manual confirmation of OCR reading; the next version can integrate browser OCR or a server-side OCR endpoint.

For reliable installation as a PWA, host these files on any static HTTPS host. The app can then be opened on Android Chrome and added to the home screen.
